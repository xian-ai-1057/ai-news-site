## 📝 重點摘要

本論文提出一種 Transformer 架構改良方案，透過在中間層加入「早期退出」（Early Exit）機制，讓模型對「容易預測」的 token 提前終止前向傳播，從而自適應地減少推理計算量，同時不犧牲任務表現。訓練流程分為兩階段：首先進行校準期訓練，讓各退出層具備預測能力；再以強化學習（RL）激勵模型盡可能在淺層退出，並以任務表現作為獎勵約束。初步實驗在小型推理模型上驗證了「模型能自適應減少跨 token 計算量」的可行性。本文作者包含劍橋大學 Puria Radmard 等六人，於 2026 年 3 月 24 日提交 arXiv（論文編號：2603.21376）。

### 研究動機：推理計算的「一刀切」困境

現有的 Transformer 模型對每一個輸出 token 都使用相同深度的網路層計算（即完整的前向傳播）。這對複雜的推理 token（需要深層抽象）是合理的，但對簡單的 token（如停用詞、語法連接詞）卻是巨大浪費。

研究問題核心：**能否讓模型「知道」何時可以在淺層就作出可信預測，從而提前退出深層計算？**

這個問題在推理模型（Reasoning Models）上尤為重要：推理模型在生成最終答案前，會先輸出大量中間「思考步驟」token（Chain of Thought），這些 token 也存在難易之分，對簡單步驟提前退出可以大幅減少總體計算成本。

### 架構設計：帶早期退出機制的 Transformer

論文在標準 Transformer 的每個（或部分）中間層之後，插入一個**退出門控模組（Exit Gate Module）**：

**退出門控模組的結構：**
- 輸入：該層的隱藏狀態（Hidden State）
- 輸出：一個二元決策——「繼續向下傳播」或「在此層退出並預測下一個 token」
- 若退出：使用該層輸出的隱藏狀態經過一個輕量級的「退出解碼頭（Exit Head）」直接預測 token

**設計優點：**
- 對「容易」的 token：在第 L 層（L << 完整深度）就退出，節省後續層的計算
- 對「困難」的 token：退出門控決定繼續，允許訊號傳播到更深層
- 整個過程對 token 序列是動態的——不同位置可以有不同的退出深度

### 訓練流程：兩階段策略

**第一階段：校準訓練（Calibration Stage）**

目標：讓各退出層的「退出解碼頭」具備足夠的預測能力，使得在該層退出的 token 預測是有意義的，而非隨機猜測。

方法：在標準 LM 訓練目標之外，對每個中間退出頭同時施加輔助的語言模型損失（Auxiliary LM Loss）。

**第二階段：強化學習激勵（RL-based Incentive Stage）**

目標：讓模型在維持任務表現的前提下，盡量選擇在更淺的層退出（節省計算）。

RL 設計：
- **行動空間（Action）**：在每個 token 生成位置，模型選擇在哪一層退出
- **獎勵（Reward）**：基於任務表現（例如：問答準確率、下游基準分數）與計算效率（退出層越早，計算效率獎勵越高）的加權組合
- **懲罰**：若退出過早導致 token 預測錯誤，給予負獎勵

這種「雙目標」RL 訓練使模型學會在精確度與效率之間取得最優平衡。

### 實驗結果

論文在小型推理模型上進行了初步驗證（作者稱為「Preliminary Results」）：

**主要發現：**
- 小型推理模型在 RL 訓練後，學會了在不同難度的 token 上採用不同退出深度
- 計算量（以 FLOPs 衡量）相較於全深度推理有可測量的減少
- 在保持基準任務表現的情況下，自適應計算減少是可行的

**局限性：**
- 目前僅在小型模型上驗證，大型模型的擴展性（Scalability）尚待研究
- 訓練的穩定性（尤其是 RL 階段）是公開挑戰
- 退出門控模組本身也帶來額外的參數和少量計算開銷

### 與相關研究的對比

**vs. NEAT（Neuron-Based Early Exit）**
NEAT 方法在神經元粒度做早期退出決策，而本論文是在層粒度做決策，概念類似但粒度不同。

**vs. Mixture of Depths（MoD）**
MoD 方法讓 token 跳過部分層（即 Skip Layers），而本論文的早期退出是允許 token 在某層完成計算並直接輸出，本質上是「提前結束」而非「跳層」。

## 💡 觀察與啟發

這篇論文代表了 AI 推理效率研究的一個重要方向：**「動態計算分配」**（Dynamic Compute Allocation）。隨著模型規模持續增大，「對每個 token 使用相同計算量」的固定代價越來越難以承受，特別是在邊緣設備部署和高並發推理場景中。

**實踐意義**：雖然論文目前僅在小型模型上有初步驗證，但這個方向對 AI 推理成本的影響可能相當顯著。以 GPT-5.5 或 Claude Opus 4.8 規模的模型，若能在 50-70% 的 token 上提前退出並維持輸出品質，推理成本可能大幅降低，直接影響商業可行性。

**研究挑戰**：RL 訓練本身的不穩定性、大規模模型的驗證缺失，以及退出門控對模型的侵入式修改，都是這個方向走向實際應用前需要克服的障礙。

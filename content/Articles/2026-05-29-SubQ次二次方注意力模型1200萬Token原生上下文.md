## 📝 重點摘要

SubQ（Subquadratic）由同名公司 SubQ Inc. 於 2026 年 5 月 5 日發布，並宣布完成 2,900 萬美元種子輪融資。SubQ 是目前已知第一個「端對端次二次方注意力」（end-to-end subquadratic attention）大型語言模型，完全避開了標準 Transformer 自注意力的 O(n²) 複雜度瓶頸，因此原生支援 1,200 萬 Token 的超長上下文窗口。這代表可以一次輸入整個程式碼庫、完整書籍或多年的對話記錄進行推理，是 Transformer 架構替代路線的重大里程碑。

## 📖 全文內容

### 發布背景

自 2017 年 Transformer 架構提出以來，自注意力（Self-Attention）的二次方計算複雜度（每個 token 需要與所有其他 token 計算注意力分數）一直是長上下文處理的根本瓶頸。雖然有許多研究嘗試用稀疏注意力（Sparse Attention）、線性注意力（Linear Attention）或狀態空間模型（SSM，如 Mamba）來繞過這個問題，但 SubQ 是第一個在端對端整個模型架構上全面採用次二次方注意力的量產規模模型。

SubQ Inc. 的 2,900 萬美元種子輪融資於模型發布同日宣布，顯示投資人對這一技術路線的信心。

### 核心技術：次二次方注意力（Subquadratic Attention）

**標準 Transformer 的問題**

在標準 Transformer 中，計算 n 個 token 序列的自注意力需要 O(n²) 的時間和空間複雜度：
- 一個 1K token 的序列需要 1M 次計算
- 一個 10K token 的序列需要 100M 次計算（增加 100 倍）
- 一個 1M token 的序列理論上需要 10¹² 次計算（幾乎不可行）

這就是為什麼即使是最先進的 LLM，長上下文窗口（如 Claude 的 200K、GPT-4 的 128K）也需要巨大的算力代價，而更長的上下文仍難以普及。

**SubQ 的解法**

SubQ 採用「稀疏次二次方注意力（Sparse Subquadratic Attention）」設計，在整個模型架構端對端（end-to-end）實現次二次方複雜度：
- 每個 token 不再與所有其他 token 計算注意力，而是通過學習的稀疏模式只與最相關的子集互動
- 稀疏注意力圖（Sparse Attention Pattern）由模型學習，而非人工預設
- 這使得計算複雜度從 O(n²) 降低至接近 O(n log n) 或 O(n)

**關鍵特點**

- **原生 1,200 萬 Token 上下文**：這是目前所有語言模型中最長的原生上下文窗口，不需要任何壓縮或分段處理
- **非 Transformer 架構**：SubQ 從根本上不是 Transformer，而是完全基於次二次方注意力設計的全新架構
- **端對端設計**：不是在 Transformer 上打補丁，而是從模型第一層到最後一層全面採用次二次方計算

### 性能表現

根據發布時的基準測試資料，SubQ 在標準語言理解和生成任務（MMLU、HumanEval 等）上的性能與同等規模的 Transformer 模型相當，同時在超長上下文任務（如 Needle-in-a-Haystack 測試）上展現出遠超競品的能力。

具體亮點：
- 在 100 萬 Token 長上下文推理任務上不出現性能衰減
- 推理速度（tokens/second）在長序列上顯著優於同等 Transformer 模型
- 訓練效率高於相同規模的 Transformer

### 市場定位與融資

SubQ Inc. 的 2,900 萬美元種子輪融資用於：
1. 擴大模型規模（更多參數的版本）
2. 建立 API 服務基礎設施
3. 擴大工程團隊

目前 SubQ 以 API 形式提供服務，主要瞄準需要超長上下文的應用場景：大型代碼庫分析、法律文件審查、科學文獻研究等。

### 技術路線的更廣闊意義

SubQ 的出現不是孤立的。在 2026 年，「Transformer 替代架構」的研究熱度空前：
- **狀態空間模型（SSM）**：Mamba、Falcon-H1 等採用線性循環計算
- **擴散語言模型（Diffusion LM）**：如 Zyphra ZAYA1-8B-Diffusion-Preview
- **次二次方注意力（Subquadratic Attention）**：SubQ 系列

這些研究方向共同指向一個趨勢：AI 社群正在探索超越 Transformer 的下一代架構，以解決計算效率和長上下文推理的根本性限制。

## 💡 觀察與啟發

SubQ 的 1,200 萬 Token 原生上下文最直觀的意義是：**一個大型企業的全年郵件記錄、一個完整軟體代碼庫、或一本長達幾百萬字的小說，都可以一次性輸入模型進行分析**。這開啟了目前 LLM 難以完成的「全域理解」任務類型。

對企業應用者而言，超長上下文意味著：不再需要 RAG（檢索增強生成）來切割長文件，而是可以直接全文輸入；AI Agent 可以「記住」更長的操作歷史；法律和合規審查可以一次處理整個合約組合。

從技術架構的角度，SubQ 驗證了「端對端次二次方設計」的可行性，可能引發下一波 LLM 架構創新浪潮。若 SubQ 能在更大規模上保持性能，Transformer 的主導地位將受到實質性挑戰。

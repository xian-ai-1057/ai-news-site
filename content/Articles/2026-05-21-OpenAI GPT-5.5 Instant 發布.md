# OpenAI 發布 GPT-5.5 Instant：幻覺減少 52.5%、Gmail 整合個人化，全面替換 ChatGPT 預設模型

## 📝 重點摘要

OpenAI 於 2026 年 5 月 5 日正式發布 **GPT-5.5 Instant**，全面取代 GPT-5.3 Instant 成為 ChatGPT 所有用戶的預設模型，並在 API 中以 `chat-latest` 識別符提供。GPT-5.5 Instant 最重大的改進是在醫療、法律、財務等高風險提示上，幻覺（hallucinated claims）減少了 **52.5%**，同時保持了前代模型的低延遲特性。此外，模型新增對過去對話、上傳檔案和 Gmail 的記憶整合，向 Plus/Pro 用戶提供更個人化的答案。此次快速更新（距 GPT-5.4 發布僅數週）再度彰顯了 OpenAI 在 AI 軍備競賽中的高頻發布節奏。

## 📖 全文內容

### GPT-5.5 Instant 的核心改進

GPT-5.5 Instant 是 GPT-5.3 Instant（前代 ChatGPT 預設模型）的直接繼任者，定位是「速度快、日常使用、個性化」的高頻互動模型（有別於 GPT-5 系列中更偏推理深度的版本）。

**改進一：幻覺大幅降低（-52.5%）**

OpenAI 內部評估中，GPT-5.5 Instant 在以下高風險提示類型的幻覺聲明（hallucinated claims）比 GPT-5.3 Instant 減少了 52.5%：
- **醫療**：藥物劑量、診斷建議、治療方案
- **法律**：法律意見、法條引用、案例援引
- **財務**：投資建議、稅務規定、財報解讀

幻覺是 LLM 最廣為人知的痛點，特別在醫療、法律、財務等「錯了有實質危害」的場景中，幻覺問題一直是企業採用的最大障礙之一。52.5% 的降幅意義重大——雖然不代表「零幻覺」，但已將風險降低到許多企業的可接受門檻。

值得注意的是，此次改進**保持了低延遲特性**——許多減少幻覺的技術手段（如更多推理步驟、更大模型）都會犧牲速度，而 GPT-5.5 Instant 成功在不增加延遲的前提下降低幻覺。

**改進二：記憶與個人化整合**

GPT-5.5 Instant 引入一個重要的個人化能力升級：可以整合多種記憶來源，提供更個人化的回答：

- **過去對話記憶**：參考歷史對話上下文，記住用戶的偏好、專案背景
- **上傳檔案**：保留對用戶上傳文件的記憶，不需每次重新上傳
- **Gmail 整合**：透過搜尋工具讀取用戶 Gmail，提供基於真實郵件內容的個人化答案

例如，用戶詢問「我上次約了 John 見面是什麼時候？」時，GPT-5.5 Instant 可以直接搜索 Gmail 回答，而不是讓用戶自己去翻信件。這是向「個人 AI 助理」方向的重要一步。

**記憶功能推出時間表**：
- Plus/Pro 用戶（桌面網頁版）：立即可用
- Free/Go/Business/Enterprise 用戶：數週內推出
- 行動版：即將推出

**改進三：記憶來源統一管理**

「Memory Sources」功能在所有 ChatGPT 消費級方案中統一推出，用戶可在設定中管理模型記得什麼、不記得什麼，以及哪些來源被授權存取。這回應了關於 AI 記憶隱私的關切。

### 部署與 API 細節

**ChatGPT 用戶端**：
- GPT-5.5 Instant 從發布日起對所有 ChatGPT 用戶（包括 Free 方案）推出
- 取代 GPT-5.3 Instant 成為預設模型
- GPT-5.3 Instant 仍可供付費用戶在三個月內透過模型設定選用，之後退場

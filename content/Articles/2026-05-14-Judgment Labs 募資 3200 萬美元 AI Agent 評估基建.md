# Judgment Labs 募資 3,200 萬美元：補上 AI agent「評估與信任」的底層基建

## 📝 重點摘要

舊金山新創 **Judgment Labs** 宣布完成 **3,200 萬美元** 種子輪 + Series A 合併募資，由 **Lightspeed Venture Partners** 領投（領投兩輪、6 個月內加碼），共同投資人包括 **Nova Global、SV Angel、Valor Equity Partners、Dynamic**。公司聚焦在「**AI agent 評估與監控的基礎設施**」，幫助企業在生產環境中即時量測 agent 的行為品質、安全性、成本，並產出可被合規部門接受的審計報告。市場切點直接命中 2026 年企業導入 agent 最痛的「**怎麼證明它真的有效、可控**」這個問題。

## 📖 全文內容

### 公司產品

Judgment Labs 提供的核心能力：

1. **多維度 agent 評估**：正確性、安全性、毒性、成本、延遲，可自訂行業特定指標。
2. **生產環境即時監控**：把 agent 的每一筆 trace 自動評分、發現異常自動報警。
3. **回歸測試套件**：每次 agent 升版前跑歷史 case，防止退化。
4. **合規審計報告**：產出可向監理單位、稽核、客戶呈遞的格式化報告。

### 為何 Lightspeed 連投兩輪

- 第一輪後 6 個月，Judgment Labs 已簽下若干 Fortune 1000 客戶。
- 企業 agent 部署規模擴大後，「可觀察性 + 評估」是 missing piece——OpenAI Eval、Anthropic 模型卡、第三方 benchmark 都無法滿足生產環境的個性化評估需求。
- 與 Datadog、Splunk、LangSmith 等既有觀察性工具屬於「補強而非取代」的關係，成長路徑明確。

### 與其他評估產品比較

| 產品 | 切點 | 與 Judgment Labs 差異 |
| --- | --- | --- |
| OpenAI Evals | 模型 benchmark | 偏 offline、單模型評估 |
| LangSmith | LangChain 應用觀察性 | 偏 trace 視覺化、評估能力較弱 |
| Datadog AI Observability | APM 延伸 | 偏系統指標而非 agent 行為品質 |
| Judgment Labs | Agent 行為品質 + 合規 | 評估 + 監控 + 審計合一 |

📚 概念對照：互動元件 ↔ 筆記原理

畫面上的迭代軌跡 ↔ 潛在空間中的多次精煉 z₀ → z₁ → … → z*（吸子模組）
「收斂殘差」指標 ↔ 固定點求解的終止條件：當 ‖z_n − z_{n−1}‖ < ε 即視為達到 z*
「隱式微分」開關 ON ↔ 利用 z* = f(z*) 的數學性質直接計算梯度（Deep Equilibrium 技巧）
「隱式微分」OFF ↔ 退化為標準反向傳播，梯度需展開整條迭代鏈，記憶體 O(N)
「自適應深度」 ↔ 簡單 token 幾步就收斂、困難 token 多算幾步——固定深度 Transformer 做不到
